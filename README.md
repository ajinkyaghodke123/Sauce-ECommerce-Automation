# SauceDemo E-Commerce Order Management Automation

This project automates **end-to-end order management workflows** on the [SauceDemo E-Commerce site](https://www.saucedemo.com/).  
It demonstrates strong skills in **Selenium WebDriver, Java, Cucumber BDD, Page Object Model (POM), and Jenkins integration**.

---

## 🚀 Project Highlights
- **Framework**: Built from scratch using **Cucumber BDD + POM**.
- **Automation Scope**:
  - Login with valid credentials
  - Add products to cart
  - Checkout process with customer details
  - Verify order confirmation
  - Data-driven testing with multiple products
- **Tools & Tech**:  
  - Java 8+  
  - Selenium WebDriver 4.x  
  - Cucumber 7.x  
  - Maven  
  - JUnit  
  - WebDriverManager
